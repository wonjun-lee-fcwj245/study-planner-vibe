## NFR 측정

### NFR-01: 초기 로딩 2초 이내

**측정 방법**: Chrome DevTools → Network 탭 → "Disable cache" 체크 → 새로고침 → Load 시간

| 측정 회차 | Load 시간 |
|----------|----------|
| 1회 | 47ms |
| 2회 | 52ms |
| 3회 | 41ms |
| **평균** | **~47ms** |

**결과: ✅ 통과** (목표 2000ms 대비 약 2.4% 사용)

### NFR-02: 학습 항목 추가 반영 200ms 이내

**측정 방법**: 체감 측정 + Performance 탭의 "Recording"

| 측정 회차 | 체감 |
|----------|------|
| 1~10회 추가 시도 | 즉시 (50ms 미만 추정) |

**결과: ✅ 통과** (목표 200ms 대비 매우 빠름. transition 0.2s는 시각 전환만 해당, 데이터 반영은 즉시)

### NFR-03: 학습 항목 추가까지 3클릭 이내

**시나리오 측정**:
1. 첫 진입 → 입력 필드는 첫 Tab으로 도달 가능 (0클릭 또는 1탭)
2. 텍스트 입력 → Enter
3. 총 클릭 수: **1클릭 이하** (Enter 사용 시 0클릭)

**결과: ✅ 통과**

### NFR-06: 외부 서버 전송 0건

**측정 방법**: DevTools Network 탭에서 앱 사용 전체 세션 모니터링

| 행위 | 발생 요청 |
|------|----------|
| 초기 로드 | index.html, style.css, app.js (모두 로컬) |
| 항목 추가 | 0건 |
| 완료 토글 | 0건 |
| 삭제 | 0건 |
| 새로고침 후 로딩 | 0건 (localStorage만) |

**결과: ✅ 통과 — 외부 전송 0건 확인**
