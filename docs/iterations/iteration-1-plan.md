## 1. 이터레이션 목표

> *"브라우저를 열어 학습 항목을 추가하고, 완료 체크하고, 삭제할 수 있다.
>  새로고침해도 데이터가 남는다. 이것만 되면 v0.1이다."*

이 한 문장에 포함되지 않는 것은 모두 이터레이션 1 범위 밖이다.

## 4. 구현 순서의 근거

이 순서는 임의가 아니다. 다음 원칙을 따른다.

**원칙 1: 가장 작은 동작 가능 단위부터.** FR-01(추가)이 없으면 다른 어떤 기능도 시작 불가.
**원칙 2: 데이터 영속성은 후순위.** 메모리에서 동작하는 걸 확인한 뒤 localStorage 추가. 이렇게 하면 localStorage 버그가 기능 버그를 가리지 않는다.
**원칙 3: FR-07은 FR-02 구현 시 동시 적용.** CSS 한 줄로 끝나는 일이라 별도 사이클로 분리하는 게 더 비효율.
