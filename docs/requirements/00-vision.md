# 프로젝트 비전 (Project Vision)

> **작성일**: 2026-5-18
> **작성자**: 이원준
> **상태**: 초안 

## 1. 한 줄 정의 (Elevator Pitch)

> 학습 일정 관리에 부담을 느끼는 **대학생**에게, **Study Planner**는
> **하루 단위의 학습 목표와 과목별 진도를 한 화면에서 가볍게 관리할 수 있는**
> **웹 기반 학습 일정 도구**이다.
> 기존의 노션·구글 캘린더와 달리, 우리 제품은
> **"학습"이라는 단일 목적에 최적화된 단순함**과
> **별도 가입 없이 즉시 사용 가능한 접근성**을 제공한다.

## 2. 문제 정의

- **해결하려는 문제**:
  대학생이 여러 과목의 학습 계획과 진도를 관리할 때, 범용 도구(노션, 캘린더)는
  기능이 많아 진입 장벽이 높고, 종이 플래너는 진도 통계를 한눈에 보기 어렵다.

- **현재 사용자가 겪는 불편**:
  1. 학습 도구를 세팅하는 데 시간이 더 걸려서, 정작 공부 시간이 줄어든다.
  2. 진도가 잘 나가고 있는지 시각적으로 확인하기 어렵다.
  3. 가입·로그인·동기화 같은 절차가 학습 시작을 미루게 만든다.


## 3. 타깃 사용자

- **주 사용자(Primary)**:
  - 학기 중에 3~6과목을 동시에 듣고 있는 대학생
  - 학교 과목 외에도 다양한 공부를 하고 있는 대학생
  - 노션이나 구글 캘린더가 과하다고 느끼는 경량 도구 선호자
  - 별도 가입을 꺼리는 사용자

- **보조 사용자(Secondary)**:
  - 자격증 시험을 준비하는 사회 초년생
  - 자기주도학습 중인 고등학생

- **명시적으로 타깃이 아닌 사용자**:
  - 팀 단위로 학습을 공유해야 하는 스터디 그룹 (다중 사용자·실시간 협업 미지원)
  - 모바일 네이티브 사용자 (본 버전은 웹 우선, 모바일은 반응형으로만 대응)
  - 1년 이상의 장기 로드맵 관리가 필요한 사용자

## 4. 핵심 가치 제안

1. **즉시성**: 가입·설치 없이 브라우저만 열면 사용 시작 가능.
2. **단순함**: 학습 관리에 꼭 필요한 기능만 — 추가, 완료, 통계 3가지.
3. **시각성**: 오늘 할 일과 주간 진도가 한 화면에서 즉시 보인다.

## 5. 성공 기준

- **사용자 측**:
  - 첫 진입부터 학습 항목 추가까지 1분 이내
  - 새로고침 후에도 데이터가 유지된다
  - 주간 진도가 한눈에 들어온다

- **기술 측**:
  - 외부 서버 의존 없이 동작 (localStorage 기반)
  - 최신 Chrome / Safari / Firefox에서 정상 동작
  - 초기 로딩 2초 이내

- **프로세스 측 (본 과제의 핵심)**:
  - 매일 또는 격일 단위로 의미 있는 커밋이 GitHub에 남아 있다
  - 요구사항 분석, 설계, 구현, 테스트의 각 단계 산출물이 문서로 존재한다
  - 바이브코딩에 사용한 프롬프트와 그 결과물의 추적이 가능하다
  - 3회의 이터레이션 회고에서 도출한 교훈이 보고서로 정리된다

## 6. 범위 (Scope)

### In Scope (이번 20일 안에 구현)
- 학습 항목 추가 / 완료 / 삭제
- localStorage 기반 데이터 영속성
- 과목 분류
- 주간 진도 통계 (간단한 차트)
- 단일 사용자, 단일 기기

### Out of Scope 
- 회원 가입 및 로그인 기능
- 클라우드 동기화, 다중 기기 지원
- 팀/그룹 공유 기능
- 알림(푸시, 이메일) 기능
- 모바일 네이티브 앱
- 다국어 지원 (한국어만)
- AI 기반 학습 추천
